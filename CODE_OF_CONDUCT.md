# Code of Conduct

This project welcomes participation regardless of background, identity, experience, or language. Treat contributors and users with respect.

## Expected conduct

- Discuss ideas and code constructively; explain disagreements with evidence.
- Respect privacy, credit others' work, and welcome questions and corrections.
- Keep issues and pull requests relevant and avoid spam.

Harassment, threats, discriminatory language, sexualized attention, publishing private information without consent, and personal attacks are not acceptable.

## Scope and enforcement

These expectations apply to project issues, pull requests, discussions, and other project-managed spaces. Maintainers may edit or remove harmful content, close disruptive threads, warn participants, or restrict participation. Decisions should be proportionate to severity and repeated behavior.

Use GitHub's **Report content** action for abuse or private-information exposure; do not repeat private information in a public issue. For non-sensitive project moderation concerns, contact the repository maintainer through an issue containing only the minimum necessary public context. You may ask for reconsideration through the same safe channel. GitHub's own Community Guidelines also apply.
